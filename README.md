# SG4 App

En drill är 18 bollar test, 3 avstånd 75,125,150m man ska sätta 2 bollar på det kortaste avståndet innan man får gå vidare när man klarat utan 150m är det 1 varv om man sätter all blir det 3 varv alltså 3.0 i score. Man kan mäta progress över tid golf
